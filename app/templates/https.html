Choose your HTTPS method

Local IP address · browser warning

Selected

Connect using Oche's local IP address. Select Enable local HTTPS to create a certificate and turn HTTPS on straight away.

The first time you connect, each browser will ask you to accept a certificate warning. Check that the address is your Oche device, then choose Advanced → Continue (in Firefox, Accept the Risk and Continue). No domain or certificate installation is needed.

Oche saves the certificate for future visits. You may see the warning again if the certificate changes or you clear your browser's saved exception.

Domain name · no browser warning

Selected

Use a domain you own to open Oche without a certificate warning on your devices. Add two DNS records once, and Oche will get and renew a trusted certificate using Let's Encrypt and acme-dns.

Oche handles registration with acme-dns. You do not need to share your DNS provider's API token or open ports on your router.

1 Prepare your domain

Use the local IP address you normally open Oche with. Keep it fixed by reserving it in your router's DHCP settings. If Oche runs in Docker, use the host device's address.

This step prepares the DNS records to copy. Domain HTTPS turns on in step 3, after Oche verifies your records and gets the certificate.

Prepare your domain to see the DNS records and the next steps.

2 Add the DNS records

Add both records in your domain's DNS settings and keep them there for automatic renewals. If you use Cloudflare, set both to DNS only (gray cloud).

The A record points your domain to Oche. The CNAME lets acme-dns handle certificate verification, so you will not need to add a new TXT record each time Oche renews the certificate.

This setup uses IPv4. Remove any AAAA record for the same Oche domain. DNS changes may take a few minutes to appear.

If your router blocks domains that point to local IP addresses, add your Oche domain to its local DNS settings.

3 Verify and activate HTTPS

Select the button below to check your DNS records and request a certificate. Oche turns on domain HTTPS as soon as the certificate is ready.

Open Play using your domain

Then open Oche using your domain name on each device. Using the local IP address will still show a certificate warning.

About the validation service and renewals

Validation service: auth.acme-dns.io. The default service is free and intended for testing. It can approve certificate requests for your Oche domain, so use a service you trust. If it is unavailable, Oche must wait to get or renew a certificate. If it loses your registration, you will need to replace the CNAME record.

While domain HTTPS is enabled, Oche checks for renewal at startup and every 12 hours. It retries failed checks after one hour and applies renewed certificates automatically. Keep Oche running so it can renew before the certificate expires.

Oche saves its settings, certificates and acme-dns credentials in its persistent data folder. Keep this folder or Docker volume when updating or reinstalling Oche.

If acme-dns no longer recognizes your registration, create a replacement below. Update the CNAME in your DNS settings, then verify again. Your current certificate stays active while you do this.
